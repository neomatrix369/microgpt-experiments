# Agent instructions

**User-facing overview and architecture** are in [`README.md`](./README.md). **Project context, layout, how to run, and conventions** are in [`CLAUDE.md`](./CLAUDE.md). Read `CLAUDE.md` first when working in this repository; it is the source of truth for what this repo is, which files to edit, and dependency constraints.

**Summary**: `microgpt` is a no-dependencies Python demo of a tiny GPT (scalar autograd + transformer). **New readers:** [`QUICKSTART.md`](./QUICKSTART.md) or [`docs/README.md`](./docs/README.md) by persona; concepts in [`docs/learn-before-you-code.md`](./docs/learn-before-you-code.md). **Autograd:** [`docs/autograd-deep-dive.md`](./docs/autograd-deep-dive.md). **Experiments:** [`docs/experiment-workflow.md`](./docs/experiment-workflow.md) (grid sweep: numbered configs `experiments/configs/0_sweep-smoke-test.json` … `4_sweep-full.json`, `python experiments/sweep.py --list-configs`; per-run **`--- Run timing ---`** in reports, **`sweep_timing.txt`** + timing columns in **`sweep_summary.csv`**; live **`elapsed … | ETA …`** on training/sweep progress lines). The main entry points are `microgpt_updated.py` (imports `mgpt/` for the model and `run_report/` for saved report text; prints sample-quality metrics; writes `outputs/output_*.txt` run reports (default `run_report.run_reports_dir(<repo root>)`; optional `--output-dir`) with optional loss-history CSV, quality blocks, and **`--- Run timing ---`** (UTC + local ISO, duration, timezone; authoritative wall clock — filename `_YYYYMMDD_HHMMSS` is for uniqueness only); **report stems encode `L`/`E`/`H`/`B`/… (no per-head-width token; `HEAD_DIM` is `N_EMBD // N_HEAD` and appears after those two in config text and in compare/HTML tables)**; **optional CLI** overrides hyperparameters per run—`python microgpt_updated.py --help`; see **README.md** sections *How to use microgpt_updated.py*, *Run experiments examples*, and *Example artifacts (preview)* for CLI coverage, sweep reproduction, and checked-in **`example-experiments/`** demos) and `microgpt.py` (compact; console output only; constants in-file only). Run with `python microgpt_updated.py` or `python microgpt.py`. To add the standard narrative to older report files, use `python annotate_run_reports.py`. To diff two reports (config in **`run_report.parse._CFG_DISPLAY_ORDER`**, **`HEAD_DIM` after `N_EMBD`/`N_HEAD`** with a calculated-field note; final loss; samples; optional run timing display; optional text loss graphs when both embed history), use `python compare_run_reports.py path/A.txt path/B.txt` with optional `--loss-bins` / `--loss-height` (exit `0`/`1`/`2`). For a multi-run HTML table (includes duration and start/end UTC/local when present), use `python experiments/report_generator.py`; for automated grid search ranked by quality score, use `python experiments/sweep.py --config experiments/configs/1_sweep-minimal.json` (see **`experiments/configs/README.md`**). Sample quality tiers: **`docs/M2-semantic-quality.md`**. Tests: `python -m pytest tests/ -q`. Details are in `README.md` and `CLAUDE.md`.

For anything not covered in `CLAUDE.md`, follow normal Python style and the existing patterns in the file you are editing.
